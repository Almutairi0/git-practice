# 📖 قاموس المصطلحات

كل ملف هنا مصطلح يحتاج تعريف. لكل مصطلح Issue مفتوحة بعنوان `Define: <term>`.

1. اختر Issue ما أحد أخذها واكتب تعليق: "أبي آخذها" عشان المنظّم يسندها لك.
2. عدّل ملف المصطلح: بدّل `TODO` بتعريف قصير بكلماتك + أمر أو مثال.
3. افتح PR واكتب في الوصف `Closes #رقم_الـIssue`.
